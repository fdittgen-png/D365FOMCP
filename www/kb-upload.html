How to produce the file

  • Set KB_PACKAGES_PATHS to the Microsoft PackagesLocalDirectory plus your customization roots (e.g. C:\Workspace\DEV\Metadata), then run npm run build:kb.
  • Upload the resulting d365fo_kb.sqlite (~1 GB). It is validated before being swapped in; a build that fails validation is rejected and the current KB is left untouched.
  • The file streams to Azure Blob Storage first, so multi-hundred-MB uploads are not subject to the request timeout.
